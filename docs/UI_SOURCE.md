# Dashboard source

Source: https://github.com/tabler/tabler
Version: @tabler/core 1.6.1
Source checkout: b168be18538753caebcb2fdcaad28a4b9f91ae7f
Official page: https://preview.tabler.io/

This dashboard adapts the complete official dashboard's page frame, metric cards, chart area and responsive grid. The compiled original card markup is preserved in static/vendor/tabler-dashboard-source-parts.json. Sales, visitors and example activity are replaced by saved model benchmark reports and local runtime records. Layout, spacing, typography and colors follow Tabler.

Tabler: MIT; Chart.js 4.4.9: MIT. Licenses are vendored beside the scripts.
